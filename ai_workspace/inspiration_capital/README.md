# Inspiration Capital (灵感资本)

> "先有资本，后有主意"

## Overview

Scatter card collection for inspiring creativity.

## Directory Structure

```
inspiration_capital/
├── README.md
├── cards/
├── scripts/
└── tests/
```

## Usage

- Create card: `python scripts/create_card.py --source "..." --trigger "..."`
- Draw cards: `python scripts/draw_cards.py --count 3`
